# Axon - Backend API

Node.js + Express + PostgreSQL + Prisma e-commerce backend.

## 📁 Location

This is the **backend** directory. The frontend is in the sibling `../frontend` directory.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start server
npm start
```

Server runs at: `http://localhost:5000`
